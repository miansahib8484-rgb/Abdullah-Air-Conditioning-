AC Error Codes Explained: Gree, LG, Daikin and Midea in Riyadh

An error code appeared on your AC display? This guide explains what the common codes mean, their likely causes and the fix, for the brands we see most in Riyadh: Gree, LG, Daikin, Midea, Samsung and Carrier.

Quick answer: An AC error code points to the part or circuit the control board flagged, such as a sensor, a fan motor, the compressor or the link between the indoor and outdoor units. Meanings differ by brand and model. Switch off at the breaker for five minutes and restart once; if the code returns, stop and call a technician.

Important note: An error code doesn't necessarily mean a major fault. Many codes are fixed by restarting the AC or cleaning the filter. But if the code repeats, call a certified technician at +966 55 292 5939 for a proper diagnosis, ignoring the code can damage the compressor.

When an unfamiliar symbol appears on the display, most people ask what it means and whether they can reset it. Whether your unit shows a blinking code without a clear explanation in the manual, or a clear code on the screen, this article covers the common codes step by step before you need to call a technician.

If the compressor seems to stop working after an error code appears, don't try repeated restarts, because that can increase the damage. And if the indoor or outdoor fan isn't spinning alongside the code, mention it when you call so the technician can bring the right part in advance and save diagnostic time during the visit.

Common AC Problems Without Error Codes — مشاكل شائعة بدون كود

🥵 AC Not Cooling

Causes: Low gas (a refill is needed), dirty filter, blocked outdoor coil, or a compressor starting to fail. Fix: Clean the filter first, if it continues, call us to check the gas level.

💧 AC Leaking Water

Common causes: Blocked drain pipe, frozen coil from low gas or a dirty filter, or the unit installed at the wrong angle. Water leaking: fix it immediately to avoid ceiling damage.

🔊 AC Making Noise

Clicking sound: a foreign object in the fan. Hissing sound: a gas leak. Vibrating sound: loose installation or a broken fan blade. Booming sound: the compressor is starting to fail, call us immediately.

⏹ AC Turns Off Automatically

Causes: Overheat protection (dirty outdoor coil), an electrical issue, or an overworked compressor. Don't ignore this, it can lead to compressor damage.

FAQ — الأسئلة الشائعة

FAQ About AC Error Codes

What does an AC error code mean?+
It's a short message from the unit's control board telling you which part or circuit it has detected a problem with, such as a sensor, fan motor, compressor or the link between indoor and outdoor units. It points to an area, not always to a broken part.
Can I clear an error code myself?+
Sometimes. Switch the AC off at the breaker for five minutes, restart it and see if the code returns. If it comes back, don't keep resetting; repeated restarts can damage the compressor.
Why does the same code mean different things on different brands?+
There's no universal standard. Each manufacturer, and often each model range, assigns its own meanings, so E1 on one brand isn't E1 on another. Check the model label and manual, or tell us the model and code and we confirm what it means for your unit.
Which brands do your error-code tables cover?+
Gree, LG, Daikin, Midea and Samsung in detail, plus Voltas, O General, Fujitsu and Haier. Treat them as a guide and confirm against your model, because meanings differ between model ranges.
Is an error code always a serious fault?+
No. Some codes come from a dirty filter, a loose connector or a brief voltage dip. But a code that returns after a reset usually means a real fault that needs a technician.
My AC light is blinking but no code is shown. What does that mean?+
Many units without a display flash an LED in a pattern, and the number of blinks is the code. Count the blinks, note the colour and tell us; that's usually enough to identify it.
Can a power cut or voltage drop cause an error code?+
Yes, especially on inverter units. A code that appears once after an outage and doesn't repeat is normally harmless. If it repeats, the control board or capacitor may be affected.
What information should I give when I call about an error code?+
The brand, model, the exact code or the number of LED blinks, and what the unit does. A photo of the display and the indoor unit label speeds it up.
Do you repair inverter control boards?+
Yes. Control board (PCB) repair typically costs 350 to 600 SAR depending on the brand and part availability, and we quote before starting. Sometimes a repair is cheaper than replacement.
Should I ignore a code if the AC still cools?+
No. An AC that still cools can be running under stress from a sensor or fan fault. Fixing it early is almost always cheaper than waiting for the compressor to suffer.
